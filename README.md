# Альбатрос — сайт albatross37.ru

Статический сайт-каталог ООО «Альбатрос» (трикотаж, Иваново) на [Astro](https://astro.build). Перенесён с WordPress (hostenko) в октябре 2026, адреса страниц сохранены.

## Запуск

```bash
npm install
npm run dev       # http://localhost:4321, правки видны сразу
npm run build     # сборка в dist/
npm run preview   # просмотр собранной версии
npm run check     # проверка типов и данных каталога
```

Нужен Node.js ≥ 22.12.

## Где что лежит

| Что править | Файл |
|---|---|
| Телефон, email, адрес, реквизиты, ссылка на прайс | `src/data/company.ts` |
| Разделы (женская/мужская/детская одежда) | `src/data/catalog.ts` |
| Тексты главной (ткани, преимущества, транспортные компании) | `src/pages/index.astro` |
| Товары категории | `src/content/catalog/<раздел>/<раздел>-<категория>.yaml` |
| Фото товаров | `src/content/catalog/<раздел>/photos/` |
| Шапка, меню, подвал | `src/layouts/Base.astro` |
| Стили | `src/styles/global.css` и блок `<style>` в компонентах |

## Как добавить товар

1. Положить фото в `src/content/catalog/<раздел>/photos/` с именами `<артикул>-1.jpg`, `<артикул>-2.jpg`, …
2. Добавить запись в `products` нужного YAML-файла:

   ```yaml
   - sku: '708'
     title: Пижама с шортами
     material: кулирка 100% хлопок
     sizes: 44-54
     images:
       - ./photos/708-1.jpg
       - ./photos/708-2.jpg
   ```

   `material`, `sizes` и `images` необязательны. Без фото карточка покажет «Фото временно отсутствуют».
3. Новая категория = новый YAML-файл с полями `title`, `cover` (необязательно, иначе раздел без обложки), `note`, `products`. Адрес страницы — `/<раздел>/<имя файла>/`, в меню категория появится сама (по алфавиту).

Фото при сборке сжимаются и конвертируются в WebP автоматически.

## Публикация

Каждый push в `main` собирает сайт и публикует его на GitHub Pages (`.github/workflows/deploy.yml`). Ход сборки — во вкладке Actions репозитория.

Сборка в `dist/` — обычные HTML-файлы, подходят для любого статического хостинга. Для временного адреса в подпапке (`evgeniybaykov.github.io/albatross37/`) сборка запускается с `BASE_PATH=/albatross37`: такая сборка закрыта от индексации и без sitemap.
